`useState` now defers a write only while a render is actually running. The check was the shared paint-window counter, which stays raised until the after-paint callback runs, so a write arriving from a user event inside that window was queued: the value React holds for the next commit lagged behind the field, and a commit in that window wrote the stale value back over what the user had typed. Writes from event handlers and effects now apply immediately, while writes made during a render still defer through the after-paint queue and `scheduleRender`'s render-later behaviour is unchanged.
